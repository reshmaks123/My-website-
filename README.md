Reshma KS – Portfolio Website
A simple personal portfolio website for a BTech Computer Science Engineering student.
Features
About Me section
Skills list
Projects section
Contact information
Navigation links to each section
Interactive button that displays a thank-you message
Technologies Used
HTML5
CSS3
JavaScript
Files
index.html – Website structure and JavaScript interaction
style.css – Website styling
How to Run
Download or clone this repository.
Keep index.html and style.css in the same folder.
Open index.html in a web browser.
Customization
Edit index.html to update the portfolio content, skills, projects, and contact information. Edit style.css to change the colors, spacing, and layout.
